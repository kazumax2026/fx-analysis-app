# 画面とWorkersのモック結合テスト

`scripts/browser-mock.test.js`はPlaywrightとChromiumを使うテストです。画面のデザインは変更せず、実データ表示は無効の既定値を維持します。

## 実行

```sh
npm ci
npm test
# 既存のChromiumがある場合
FX_BROWSER_PATH=/usr/bin/chromium npm run test:browser
# Playwrightのブラウザーを使う場合は、テスト環境で以下を実行
npx playwright install chromium
npm run test:browser
```

ブラウザーの導入にはネットワークと必要なOSライブラリが必要です。ブラウザーテストは通常の`npm test`と分けています。

## 結合経路

合成のTwelve Data形式OHLC → WorkerのOHLC検証・共有予算管理 → モックHTTP応答 → ブラウザーのデータ取得・指標計算 → 実際の画面。

Node内で一時的なローカル配信サーバーを起動し、テスト終了時に閉じます。Workersは実デプロイせずNode内で実行し、認証はモック、保存先はテスト用の一時ファイルです。APIキーは渡しません。

既定設定を確認するテストでは実データボタン無効と取得通信ゼロを検証します。接続テストでは、ブラウザーへの配信時だけデータ取得モジュールの設定を差し替えます。保存済みのLIVE_CONFIGは変更しません。モック配信先は`.test`ドメインで、全応答をPlaywrightが横取りします。ローカルとモック以外のブラウザー通信は遮断し、発生すればテスト失敗です。

モック画面の「実データ」ラベルは、本番モードを模擬した表示確認です。テストで使用する内容はすべて合成データであり、Twelve Dataから取得した価格ではありません。

## 検証内容（ブラウザーテスト7件）

- iPad相当1024×1366、1366×1024：3通貨の確定5分足、終値、RSI、MA/MACDの描画、日本語判定理由、タップ操作、横方向のはみ出し
- 既定設定：3通貨×5時間足サンプルと実データ取得通信ゼロ
- 通信エラー・データ不足：日本語説明と判定不可、サンプルへの明示的な復帰
- 古いデータ：参考チャートは残し売買判定は停止
- 表示後の期限切れ：テスト時計を進め更新停止を確認。再取得失敗でも前回データを参考表示
- 連続切替：応答を意図的に遅延し、通貨・時間足切替後に届いた古い応答が画面を上書きしないことを確認

各テストでブラウザーのJavaScriptエラーがないことも確認します。

## 今回の修正

WorkersがHTTPエラーで返すINSUFFICIENT_DATAを、フロントで日本語の「データ不足」に変換します。既知のコードだけを解釈し、配信元の任意のメッセージは表示しません。stale応答は取得期限だけでなく、古い相場データも含むため、更新停止メッセージを明確にしました。
